# AutoML Studio

A No-Code Machine Learning Platform for training, evaluating, and deploying ML models.

## Features

- CSV Upload
- Automatic Data Cleaning
- Auto Feature Detection
- Classification
- Regression
- Model Comparison
- Experiment Tracking
- REST API Deployment

## Installation

### Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```

## Tech Stack

- Next.js
- FastAPI
- PostgreSQL
- Scikit-Learn
- Docker
